Generador de documentos desde plantilla

Sube un documento que ya tienes — un presupuesto, contrato o informe — y la skill lo convierte en plantilla reutilizable. La próxima vez que necesites el mismo documento para otro cliente, lo genera en segundos sin tocar el formato original.

Cómo funciona

Dos fases, un mismo problema resuelto

La mayoría de los documentos de una empresa son siempre el mismo documento con datos distintos. Esta skill convierte ese proceso manual — abrir el Word, buscar el nombre del cliente, cambiar la fecha, el importe — en algo que hace Claude en segundos.

Fase A · Plantillar

Del documento real a la plantilla

Sube un documento tuyo ya relleno. La skill identifica qué partes son datos variables — nombre, fecha, importe, NIF — y los sustituye por marcadores {{campo}} conservando el formato exacto.

Fase B · Rellenar

De la plantilla al documento nuevo

Pasa la plantilla y los datos del nuevo cliente. Claude genera el documento final con todos los campos correctamente rellenados — mismo membrete, misma tipografía, mismo layout.

Para quién es

Si repites el mismo documento cambiando solo los datos, esto es para ti

Diseñada para gestorías, despachos, consultorías e inmobiliarias que generan volumen de documentación similar — presupuestos, contratos, informes periódicos, cartas a clientes.

También funciona si preparas propuestas comerciales o cualquier tipo de documento repetitivo donde el formato es siempre el mismo y solo cambian los datos.

Instalación

En menos de dos minutos

01

Descarga el archivo .skill

Es un archivo comprimido con todo lo que necesita la skill para funcionar.

02

Extrae en .claude/skills/

Dentro de tu proyecto, crea la carpeta .claude/skills/generador-documentos/ y extrae ahí el contenido del .skill.

03

Dile a Claude que la use

Abre Claude Code, sube tu documento y escribe: "convierte esto en plantilla" o "genera este presupuesto para otro cliente con estos datos". Claude activa la skill automáticamente.
